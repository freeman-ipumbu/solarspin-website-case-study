# Publication boundary

## Why this repository exists

SolarSpin's website is a public company experience, but its production repository is private. This case study creates a useful public record without turning deployment source into a public template.

## Included

- the problem and design brief
- approved interface screenshots
- experience and interaction architecture
- visual-system rationale
- accessibility and QA scope
- Freeman Ipumbu's role
- the public production URL

## Excluded

- production HTML, CSS and JavaScript
- Cloudflare account data and deployment credentials
- private analytics
- contact records
- unpublished identity working files
- source code or private records from showcased client and venture projects
- prospect identities and confidential proposal material
- security-sensitive infrastructure detail

## Project claims

The screenshots record the October 2026 release, including the short branded ignition, corrected Project Observatory navigation and heading composition, cinematic Field Atlas, interactive Milky Way-to-Windhoek address, live Windhoek transmission and final SolarSpin Experience sign-off. The live site can continue to evolve after this case study is published.

References to accessibility describe implementation decisions and an automated QA run. They are not a claim of formal certification.

References to projects preserve their own public boundaries. In particular, the fuel-retail platform remains anonymous, controlled pilots are not described as production deployments, and protected operational data is not reproduced here.

## Reuse

The repository is public for viewing, evaluation and reference. Public visibility does not grant permission to copy the SolarSpin identity, artwork, writing or interface as a commercial template. See the repository license for the exact terms.
