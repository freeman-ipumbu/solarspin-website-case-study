# Publication boundary

## Why this repository exists

SolarSpin's website is a public company experience, but its production repository is private. This case study creates a useful public record without turning deployment source into a public template.

## Included

- the problem and design brief
- approved interface screenshots
- experience and interaction architecture
- visual-system rationale
- accessibility and QA scope
- Freeman Ipumbu's role
- the public production URL

## Excluded

- production HTML, CSS and JavaScript
- Cloudflare account data and deployment credentials
- private analytics
- contact records
- unpublished identity working files
- source code or private records from showcased client and venture projects
- Ontoko customer names, phone numbers, addresses, map coordinates, order records and admin-session data
- prospect identities and confidential proposal material
- security-sensitive infrastructure detail

## Project claims

The screenshots record the October 2026 release, including the short branded ignition, corrected Project Observatory navigation and heading composition, cinematic Field Atlas, current Ontoko Foods client feature, interactive Milky Way-to-Windhoek address, live Windhoek transmission and final SolarSpin Experience sign-off. The live site can continue to evolve after this case study is published.

References to accessibility describe implementation decisions and an automated QA run. They are not a claim of formal certification.

References to projects preserve their own public boundaries. In particular, the fuel-retail platform remains anonymous, controlled pilots are not described as production deployments, and protected operational data is not reproduced here. TPTS Grid is identified as a TPTS-owned product with a SolarSpin-built digital experience; its public destination anchors are not live OTA inventory, and the pilot does not process bookings or payments.

Ontoko Foods is presented as a live story, egg-order and general-enquiry system with an optional device-local return-client profile, OpenStreetMap delivery pinning and a protected admin desk. The public screenshot records only visitor-facing interface state and contains no customer or admin data. Every order remains subject to human confirmation of stock, price and fulfilment. Cash order requests are live. OneGate-hosted EFT / Pay by Bank, Google Pay and Apple Pay remain activation-gated until Ontoko has its payment-capable merchant profile and settlement configuration. This case study does not claim that those online methods are processing payments.

Featuring Ontoko changes the current editorial emphasis, not the portfolio inventory. SolarSpin still presents 30 public project stories across four orbits.
